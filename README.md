# StudyTrack – Student Study Planner

A small study planner made with HTML, CSS and vanilla JavaScript.

## Features
- Add tasks with a priority and optional due date
- Mark tasks as completed
- Filter pending and completed tasks
- Delete tasks
- Save tasks in browser Local Storage

## Run it
Open `index.html` in a browser. No installation is required.

## What I practised
DOM manipulation, event listeners, arrays, filtering, and Local Storage.
