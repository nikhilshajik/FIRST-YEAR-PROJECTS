# Beginner Web Development Portfolio

A collection of small front-end projects built while practising HTML, CSS and JavaScript.

## Projects
1. **StudyTrack** – a study task planner with priorities, filters and Local Storage.
2. **CampusConnect** – a college event discovery page with category filters.
3. **SpendSmart** – a personal income and expense tracker with Local Storage.

## Run a project
Open the project's `index.html` file in a web browser. These projects use plain HTML, CSS and JavaScript; no build tools are needed.

## Learning focus
- Semantic HTML and responsive CSS
- JavaScript arrays, objects and functions
- DOM manipulation and event handling
- Browser Local Storage
- Writing project documentation

These are learning projects. Update the sample content, test the features and make changes of your own as you learn.

## Publish with GitHub Pages
1. Create a public repository named `beginner-web-projects`.
2. Upload the contents of this folder (including the root `index.html` and all three project folders).
3. Open **Settings → Pages** in the repository.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub Pages finishes deploying, the portfolio landing page will link to all three projects.
